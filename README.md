# Obstacle Avoidance Car (Arduino)

An autonomous car built on Arduino (2025).

## What it does
- Detects obstacles in real time with ultrasonic sensors
- Uses motor control logic to navigate around obstacles without collisions

## Skills used
Arduino, ultrasonic sensors, motor control, embedded programming.
