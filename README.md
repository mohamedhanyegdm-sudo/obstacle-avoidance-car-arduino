# Obstacle Avoidance Robot Car

An obstacle avoidance robot car designed and built using sensors and a microcontroller (Arduino, 2025).

## What it does
- Detects obstacles in real time with ultrasonic sensors
- Uses motor control logic to navigate around them automatically, without collisions

## What it demonstrates
Embedded systems, basic robotics, and problem-solving through hands-on implementation.

## Skills used
Arduino, ultrasonic sensors, motor control, embedded programming.
